# 软件禁止联网工具

这是一个 Windows 本地小工具。选择软件安装目录后，它会扫描目录内的 `.exe` 文件，并为选中的程序创建 Windows 防火墙出站阻止规则。

## 使用

1. 双击 `run.bat`。
2. 点击“以管理员身份重启”。
3. 点击“选择安装路径”。
4. 确认要处理的 `.exe`。
5. 点击“一键禁止联网”。

## 解除

重新选择同一个安装路径，扫描后点击“解除选中阻止”。

## 说明

- 只阻止出站联网，不删除文件，不修改软件安装目录。
- 防火墙规则名前缀为 `NetBlocker`。
- 部分软件可能通过服务、更新器或浏览器组件联网，需要把相关 `.exe` 一并选中。
